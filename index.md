# Privacy Policy for REI-DSP.SA

**Last updated:** October 11, 2026

REI-DSP ("we", "us", or "our") provides the **REI-DSP.SA** Android application (package name: `com.rei.sa`).

This Privacy Policy explains what information REI-DSP.SA accesses and how it is handled.

## Summary

REI-DSP.SA is a spectrum analyzer application for Android devices used with a supported radio receiver connected over USB. All of its processing takes place on the user's device.

REI-DSP.SA:

- does not require registration or an account;
- does not display advertisements;
- does not use advertising, analytics, telemetry, crash-reporting, remote-configuration, or cloud services;
- does not collect device identifiers;
- does not sell or share user data;
- does not request Android's permission for Internet access, so it cannot connect to the Internet or transmit data itself;
- does not require an Internet connection.

## Location

REI-DSP.SA asks for permission to use the device's precise location. Before Android shows its permission request, the application explains why the location is needed.

The location is used for one purpose only: to determine whether the device is in a country where the application may be used. REI-DSP.SA does not operate on the territory of the Russian Federation. The English interface becomes available once the device's location has been determined to be outside that territory; until then, the interface is available in Ukrainian only.

The user may decline the location permission. The application then continues to work, with its interface in Ukrainian only.

The location is read only while the application is open on the screen. REI-DSP.SA does not access location in the background.

The device's coordinates are processed only in the device's memory. They are never written to a file or a log, and they never leave the device. The application may store the result of the location check on the device, for example to apply it at the next start, and a coded entry about it in its diagnostic log.

## Radio Access over USB

REI-DSP.SA works with a supported radio connected to the device over USB. Android asks the user to allow the application to access the connected radio. The application uses this access only to control the radio and to receive its signal data.

## Radio and Spectrum Data

REI-DSP.SA processes radio signal data (IQ samples) received from the connected radio or read from files the user imports. This processing takes place on the device.

Recordings contain the signal data and technical information about the recording, such as the frequency range, sample rate, gain, date and time, and the application version.

Depending on the signals received, recordings may contain information carried by radio transmissions. Users are responsible for complying with applicable laws and regulations concerning the reception, recording, storage, sharing, or use of radio transmissions.

## Files and Storage

REI-DSP.SA does not request permission to access the device's shared storage.

The application keeps its own data in its application folder on the device: IQ recordings, settings, a list of application events, and diagnostic logs. Android deletes this folder when the application is uninstalled.

When the user exports a recording, or when the application saves a screenshot, the file is written to the device's shared **Download/REI-SA** folder. There it is available to the user through Android's Files application, other file managers, and a USB connection to a computer. The application keeps the 100 most recent screenshots and deletes older ones.

To import recordings made with other equipment, the user chooses a folder and files in Android's own file chooser. REI-DSP.SA receives read-only access to what the user has chosen and nothing else. It converts the selected files into a copy in its own application folder; the original files are not changed.

## Sharing

REI-DSP.SA does not send files or data to other applications, services, or people.

Files in the shared Download/REI-SA folder can be opened, copied, or shared by the user with other applications. Those applications handle the files under their own privacy policies; REI-DSP has no control over them.

## Data Collection and Sharing by REI-DSP.SA

REI-DSP.SA does not collect or transmit:

- personal information;
- location information;
- device identifiers;
- spectrum or IQ data;
- recordings;
- user files;
- usage information;
- diagnostic logs.

REI-DSP does not sell, rent, or share user data.

## Permissions and Device Access

REI-DSP.SA uses:

- location (precise and approximate), for the purpose described in the Location section, only while the application is open;
- access to the connected radio over USB, which Android asks the user to approve;
- read-only access to a folder and files the user chooses for import in Android's file chooser.

REI-DSP.SA does not request access to:

- the Internet;
- shared storage;
- the microphone;
- the camera;
- contacts;
- Bluetooth or nearby devices;
- notifications;
- location in the background.

## Android, Google, and Unity Components

REI-DSP.SA is built with Unity and runs on the Android operating system. It does not include Unity Analytics, Unity Ads, Firebase, Google Analytics, crash-reporting, cloud, or remote-configuration services.

Android, Google Play, the device manufacturer's software, and other system components operate under their own settings and privacy policies, which REI-DSP does not control. For example, where Android's backup or device-transfer features are enabled on the device, Android may copy application data under the terms of Google or the device manufacturer. REI-DSP has no access to such copies.

## Data Retention and Deletion

REI-DSP does not operate servers and holds no copy of any user data.

Recordings, settings, and logs in the application's folder remain on the device until the user deletes them in the application, or until the application is uninstalled, which deletes that folder.

Exported recordings and screenshots in the shared Download/REI-SA folder remain after the application is uninstalled. The user can delete them with a file manager.

## Security

All processing takes place on the device, and the application has no Internet access.

Users are responsible for the security of their device and of the files they export, copy, or share.

## Children's Privacy

REI-DSP.SA is intended for users aged 13 and older. It is a technical application for users with relevant technical knowledge and is not directed to children under 13.

REI-DSP.SA does not collect personal information from anyone, including children.
