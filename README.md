# Privacy Policy for REI.SA

**Last updated:** October 6, 2026

REI ("we", "us", or "our") provides the **REI.SA** Android application (package name: `com.rei.sa`).

This Privacy Policy explains how REI.SA accesses and handles information.

## Summary

REI.SA is a spectrum analyzer application for Android. Its application functionality and user data processing are performed locally on the user's device.

REI.SA:

- does not require user registration or an account;
- does not display advertisements;
- does not use advertising or analytics services;
- does not sell or share user data;
- does not intentionally transmit spectrum data, location data, user files, or other user-created data to REI or to third parties;
- does not require an Internet connection for its normal application functionality.

## Location

REI.SA may request access to the device's location.

Location information accessed by REI.SA is processed locally on the device and is not intentionally transmitted by REI.SA to REI or to third parties.

**Before publishing this policy, replace this paragraph with the exact purpose for which REI.SA requests location permission.**

## Files and Storage

REI.SA may access files or device storage so that users can save application data and open previously saved or user-selected files.

This may include spectrum measurements, recordings, screenshots, logs, configuration information, exported data, or other files created or selected by the user.

Files accessed or created by REI.SA are processed locally. REI does not intentionally receive or upload these files.

## Radio and Spectrum Data

REI.SA may process and store radio-frequency spectrum data and related measurements obtained from supported radio hardware or data files.

This processing is performed locally on the user's device. REI.SA does not intentionally upload radio or spectrum data to REI or to third parties.

Depending on the equipment used and the signals received, locally stored recordings or measurement files may contain information originating from radio transmissions.

Users are responsible for complying with applicable laws and regulations concerning the reception, recording, storage, or use of radio transmissions.


## Sharing Files

REI.SA provides a user-initiated sharing feature using the Android system sharing interface.

When the user chooses to share an IQ file or other application-generated file, Android displays available applications or services that can receive the selected file. REI.SA does not automatically transmit these files and does not select the destination on the user's behalf.

Once the user selects another application or service, the file may be processed, copied, uploaded, or transmitted by that application according to its own functionality and privacy policy.

REI has no control over how third-party applications or services handle data that the user explicitly chooses to share with them.

## Data Collection and Sharing by REI.SA

REI.SA itself does not intentionally collect or transmit personal information, location information, spectrum data, recordings, user files, or usage information to servers operated by REI.

REI does not sell, rent, or share user data collected through REI.SA.

## Android, Google, and Unity Components

REI.SA is built using Unity and runs on the Android operating system.

The application does not intentionally integrate advertising, analytics, user-account, or cloud-storage services.

However, Android, Google Play, Google Play services, Unity runtime components, or other platform components present on a user's device may independently process limited device, diagnostic, security, installation, or usage information according to their own configurations and privacy policies.

Such platform-level processing is separate from REI.SA's own application data processing and may depend on the user's device, operating-system configuration, installed services, and privacy settings.

For more information, users should consult the privacy documentation provided by Google, Android, Unity, and their device manufacturer.

## Data Retention and Deletion

REI does not maintain a remote database containing REI.SA user data.

Data created by REI.SA is stored locally on the user's device and remains there until it is deleted by the user, by the application, or by the Android operating system.

Application-private data is normally removed when the application is uninstalled. Files saved to shared storage, external storage, or another user-selected location may remain after the application is uninstalled and may need to be deleted separately by the user.

## Security

Because REI.SA processes its application data locally, user-created data remains under the control of the user's device and selected storage locations.

Users are responsible for the security of their device and any files they choose to export, copy, or share through other applications or services.

## Children's Privacy

REI.SA does not knowingly collect or transmit personal information from children or other users to servers operated by REI.

The application's own data processing described in this policy is performed locally on the user's device.
