# Privacy Policy for REI.SA **Last updated:** October 6, 2026 REI ("we", "us", or "our") provides the **REI.SA** Android application (package name: `com.rei.sa`). This Privacy Policy explains how REI.SA accesses and handles information. ## Summary REI.SA is a spectrum analyzer application for Android. Its application functionality and user data processing are performed locally on the user's device. REI.SA: - does not require user registration or an account; - does not display advertisements; - does not use advertising, analytics, telemetry, crash-reporting, remote-configuration, or cloud services; - does not collect device identifiers; - does not sell or share user data; - does not initiate network connections or transmit user data over the Internet; - does not require an Internet connection for its normal operation. ## Location REI.SA may request access to the device's **precise location** while the application is open. Location access is used only as part of the application's protection and security mechanisms. Location information is processed locally on the user's device. REI.SA does not transmit location information to REI, share it with third parties, or transfer it outside the device. REI.SA does not access location in the background. ## Files and Storage REI.SA may access files or device storage so that users can save application data and open previously saved or user-selected files. This may include: - IQ recordings; - spectrum measurements; - screenshots; - configuration data; - exported data; - other files created or selected by the user. Files accessed or created by REI.SA are processed locally on the device and are not automatically uploaded or transmitted. When a user deletes a file through REI.SA, the file is removed from storage. ## Radio and Spectrum Data REI.SA may process and store radio-frequency spectrum data, IQ data, and related measurements obtained from supported radio hardware or data files. This processing is performed locally on the user's device. REI.SA does not automatically upload, transmit, monitor, or store this data on servers operated by REI. Depending on the equipment used and the signals received, locally stored recordings or measurement files may contain information originating from radio transmissions. Users are responsible for complying with applicable laws and regulations concerning the reception, recording, storage, sharing, or use of radio transmissions. ## Sharing Files REI.SA provides a user-initiated sharing feature using the Android system sharing interface. When the user chooses to share an IQ file or other application-generated file, Android displays available applications or services that can receive the selected file. REI.SA does not automatically transmit these files and does not select the destination on the user's behalf. Once the user selects another application or service, the file may be copied, processed, uploaded, or transmitted by that application according to its own functionality and privacy policy. REI has no control over how third-party applications or services handle data that the user explicitly chooses to share with them. ## Data Collection and Sharing by REI.SA REI.SA does not intentionally collect or transmit: - personal information; - location information; - device identifiers; - spectrum or IQ data; - recordings; - user files; - usage information; - diagnostic logs containing personal or device information. REI does not sell, rent, or share user data collected through REI.SA. ## Permissions and Device Access REI.SA currently uses permissions required for its local functionality, including location and file/storage access. REI.SA does not use: - microphone access; - camera access; - Bluetooth or Nearby Devices access; - clipboard access; - WebView-based online content; - background location access. ## Android, Google, and Unity Components REI.SA is built using Unity and runs on the Android operating system. REI.SA does not intentionally integrate Unity Analytics, Unity Ads, Firebase, Google Analytics, crash-reporting services, cloud services, remote configuration, or similar online services. The application itself does not initiate network connections for user data processing. Android, Google Play, Unity runtime components, device-manufacturer software, or other platform components installed on the user's device may operate independently of REI.SA according to their own configurations and privacy policies. REI does not control such platform-level processing. ## Data Retention and Deletion REI does not maintain a remote database containing REI.SA user data. Data created by REI.SA remains on the user's device until it is deleted by the user, by REI.SA, or by the Android operating system. Application-private data is normally removed when the application is uninstalled. Files saved to shared storage, external storage, or another user-selected location may remain after the application is uninstalled and may need to be deleted separately by the user. ## Security REI.SA processes application data locally on the user's device. Users are responsible for the security of their device and for any files they choose to export, copy, or share through other applications or services. ## Children's Privacy REI.SA is not specifically designed for or directed to children under 13. It is a technical spectrum-analysis application intended for users with relevant technical knowledge. REI.SA does not knowingly collect or transmit personal information from children or other users to servers operated by REI. ## Changes to This Privacy Policy This Privacy Policy may be updated if REI.SA's functionality, permissions, third-party components, or data-handling practices change.
